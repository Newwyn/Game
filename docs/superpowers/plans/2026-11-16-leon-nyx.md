> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm 2 anh hùng chơi được trọn vẹn: Nyx (`voidmage`, pháp sư niệm lâu dùng hiệu ứng pixelfx) và Leon (`chessmaster`, triệu hồi 6 quân cờ bằng 3 nút đổi theo thế cờ).

Máy khách nhận sự kiện riêng `voidFx` / `chessFx` và vẽ bằng `spawnPixelFx` + tấm hiệu ứng vẽ tay. Tranh làm song song, trong lúc chờ dùng hình tạm.

**Tech Stack:** Node (CommonJS) + socket.io phía máy chủ; Vite + Three.js + ES modules phía máy khách; test bằng `node:test`; tranh qua `tools/codex_draw.js`, Flow, `tools/sprite_pack.py`, `tools/fx_grid_pack.py`.

**Spec:** `docs/superpowers/specs/2026-11-16-leon-nyx-design.md` — mọi con số lấy từ đó; bản này chỉ thêm tên hàm, tên sự kiện, tên file và test.
